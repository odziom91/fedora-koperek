# HeadsetControl

RPM packaging for [HeadsetControl](https://github.com/Sapd/HeadsetControl), a utility for controlling supported USB headsets on Linux.

- **Version:** 4.2.0
- **Source:** [Sapd/HeadsetControl](https://github.com/Sapd/HeadsetControl)
- **Packaging:** Based on the original upstream RPM SPEC file, with modifications if needed for this repository.
- **Repository:** [fedora-koperek](https://github.com/odziom91/fedora-koperek)

This package is maintained for personal use and provided as-is, without any guarantees of stability, compatibility, or reliability.

Use at your own risk.
