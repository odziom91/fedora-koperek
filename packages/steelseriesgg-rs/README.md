# steelseriesgg-rs

Open-source SteelSeries GG replacement for Linux.

Upstream: https://github.com/Ven0m0/steelseriesgg-rs

## Included

- ssgg command-line application
- systemd user service
- udev rules for SteelSeries devices

## Build

Built from upstream source using Fedora COPR.
